# User Stories

1. As a parent or guardian, I want to retrieve up to 10 available videos from my selected YouTube channel, so that I could identify potentially concerning Elsagate content for further review. (FR1)

Acceptance criteria:
a. The YouTube channel I would like to review should be available after I search for it.
b. Up to 10 available videos should be retrieved after I select the YouTube channel.

2. As a parent or guardian, I want to view the flagged video frames and the concern level (low, medium, high) of each videos, so that I can identify which videos that need closer review. (FR2)

Acceptance criteria: 
a. A YouTube channel must be selected first before its videos are retrieved and analyzed. 
b. The system must succesfully process the retrieved video frames for the deep learning algorithm to analyze them.

3. As a parent or guardian, I want to view my past YouTube channel screening history that was done in the last 30 days, so that I can refer to the channels I have reviewed. (FR3)

Acceptance criteria:
a. There should be a history tab in the dashboard that is accessible for me to use.
b. At least one screening activity is attempted in the past 30 days for its results to appear in the history tab, otherwise there would be no records displayed.
